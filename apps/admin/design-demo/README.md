# Admin 像素风设计 Demo

三种像素风并排预览，仅静态 HTML（不接真实数据/逻辑），供选型。

## 打开方式

直接双击 `pixel-styles.html`，或：

```bash
open apps/admin/design-demo/pixel-styles.html   # macOS
```

顶部 tab 切换三套风格，用的是 admin 仪表盘布局（顶栏 + KPI 卡 + 图表占位 + 表格）。

## 三套风格

| | 风格 | 字体 | 调子 | 适合 |
|---|---|---|---|---|
| **A** | 现代像素 / 新拟态 | Press Start 2P（仅标题/KPI）+ 普通中文 | 高饱和彩色 + 零圆角 + 3px 黑边 + 6px 硬投影 | 信息密度高的后台，一眼像素但保可读（推荐） |
| **B** | 复古游戏机 GB | Press Start 2P 全局 | GameBoy 四阶墨绿 + 粗描边 | 最强游戏感；数据密集页可读性偏弱 |
| **C** | CRT 终端 | VT323 等宽 | 绿荧光 + 扫描线 + 深色 | 黑客终端气质，与现有深色主题 mono-tool 呼应 |
| **D** | 街机电玩 / FC 霓虹 | Press Start 2P（标题/数字）+ Silkscreen（标签）+ 点阵中文正文 | 深色街机柜底 + 霓虹青/品红/黄/绿 + 硬投影粗边 + HUD 细节 | 古早电玩感又保可读，最像“游戏机后台” |

## 现有主题 token 能直接套用吗？

**不能直接复用现有 4 套主题的值，但架构完全兼容。** 现有 4 套（暖橙/深灰/柔粉/紫渐变）都是“柔和现代”取向——圆角、柔和阴影、低饱和描边；像素/街机风要的是零圆角、高饱和霓虹、硬投影、粗边，值上冲突。

正确做法：**把像素风做成新增的一套主题**——沿用同一组 `--lb-*` 变量名，换一组值（`--radius:0`、霓虹色板、硬投影 `--lb-shadow-*`、粗描边），再加少量像素化工具类。这样与现有主题一键切换、随时回退，页面/组件代码不用改。

## 可行性（落地到真实 admin）

admin 现有架构是 **shadcn 语义变量 → `--lb-*` 两层桥接**，像素风可做成**第 4 套主题**，不改页面/组件代码，只需：

1. 新增一份 `pixel` token 覆盖（`--radius:0`、像素色板、硬投影 `--lb-shadow-*`、粗描边）。
2. 引像素字体（英文 Press Start 2P / VT323；中文需 Zpix 或 fusion-pixel，体积几百 KB，建议只对标题/数字用像素字、正文用普通等宽以控体积与可读性）。
3. 少量像素化工具类（硬边框 `.pixel-border`、硬投影 `.pixel-shadow`）。
4. Recharts 关圆角/抗锯齿做“硬边像素感”（直角柱、方点），配色走新色板；不做逐格位图重绘（成本高、收益低）。

**成本**：字体体积、像素图标（lucide 是矢量线条，严格像素需一套像素图标或接受“线条图标 + 像素外壳”混搭）。

选定后按“第 4 套主题”实现，可与现有现代风一键切换、随时回退。
