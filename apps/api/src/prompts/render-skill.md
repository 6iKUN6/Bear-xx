# 视频渲染能力

当任务要求把一段 HTML 内容做成视频时，调用 renderHtmlToVideo 工具。

## 何时使用

- 需要把 HTML 分镜 / 画面渲染成 mp4 成片时。
- 用户明确要「视频」「成片」「渲染」时。

## 渲染要求

- HTML 必须暴露 `window.renderFrame(timeSeconds)` 接口，渲染器据此逐帧推进画面；缺这个接口会渲染失败，请先补上再调用。
- 宽度与高度必须是偶数（H.264 编码要求），常见竖屏为 1080×1920、横屏为 1920×1080。
- 时长（秒）与帧率共同决定总帧数，按内容节奏选择，不要无限拉长。

## 完成后

- 工具返回成片在对象存储上的地址，把它原样告知用户即可，不要自行拼接下载 URL 或编造地址。
- 如果同一份 HTML 已经渲染过，工具会直接复用已有成片，这是预期行为。
