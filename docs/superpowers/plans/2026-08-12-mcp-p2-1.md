# MCP P2-1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将麦当劳 MCP 以受白名单约束的工具组接入 Agent 运行时，并为工具调用 trace 写入 MCP 来源。

**Architecture:** `McpClientManager` 是 MCP server client、工具清单、健康状态的唯一所有者；目前只注册麦当劳，但按 server id 维护状态，便于后续增加 server。`CapabilityRegistry` 显式等待 manager 初始化后加载审核工具，登记到 `mcd-order`，并维护 tool -> MCP 元数据映射；`ConversationTraceService` 在持久化工具事件时查询该元数据并写入既有列，不扩展 SSE 契约。

**Tech Stack:** NestJS 生命周期、`@langchain/mcp-adapters`、LangChain tools、Jest、PostgreSQL trace（无 schema 变更）。
