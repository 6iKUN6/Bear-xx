# 智能体默认回复与首字头像设计

## 目标

- 移除内置的默认智能体图片资产及全部引用。
- 当 `Agent.avatar` 为空或图片加载失败时，以智能体名称的首个 Unicode 字符作为头像内容。
- 管理端可将一个已启用的智能体设为全局默认回复智能体。

## 范围与语义

复用既有 `Agent.isDefault`，不增加数据字段或迁移。默认智能体仅用于运行时未给出 `agentId` 的普通聊天；会话明确指定的智能体仍优先，群聊的成员路由和会话级 `Conversation.defaultAgentId` 保持不变。

数据库在任意时刻只保留一个全局默认智能体。管理端不提供将当前默认智能体取消为“无默认”的操作，也不能停用当前默认项。目标智能体必须已启用，避免默认解析回退至合成智能体。

## 接口与数据流

- 新增管理员专用的“设为默认回复”接口，仅接收目标智能体 ID。
- 服务层在可串行化事务内校验目标存在且已启用，再清除其他 `isDefault` 标记并标记目标；序列化冲突有限重试后仍失败时透传错误。停用和删除智能体也在相同的事务边界内确认其不是默认项；成功后失效 `AgentDefinitionService` 缓存。
- 管理端智能体列表为非默认项展示该操作，成功后刷新列表；当前默认项继续标注“默认回复”。

## 头像展示

- Admin 将头像渲染收敛为同一组件：有有效 URL 时显示图片；空值或加载失败时展示名称首字。
- 小程序将现有字符串地址工具替换为可复用的“是否有头像 + 首字”判断，并在所有智能体头像位置使用相同的首字回退。
- 名称取 `Array.from(name.trim())[0]`，空名称显示 `?`。首字头像使用既有主题色和圆形容器，不保留图片背景。
- 管理端编辑抽屉的预览也遵循同一规则。移除旧图片资产，并移除资产 README 中对应导入示例与清单条目。

## 错误处理与验证

- 设默认失败时返回明确的 404 或 400，管理端展示请求错误且不更新本地列表。
- 覆盖服务层的默认切换事务、停用智能体不可设为默认、切换后缓存失效。
- 覆盖首字提取的中文、英文、空白名称，以及头像加载失败时的前端回退状态。
- 完成后运行 API 单测与构建、Admin 构建、移动端类型检查和小程序构建。
