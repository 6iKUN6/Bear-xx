Litter Bear · 单聊 / 群聊 UI 设计稿

信息架构：底部恢复三 Tab（聊天 / 智能体 / 我的）。聊天 Tab 维持「直显最近会话 + 历史抽屉」； 「智能体」Tab 是通讯录（网格卡片 → 单聊；右下角发起群聊 → 多选建群）；群聊沿用 @ 提及 + 成员条， 标题栏进入成员管理（随时加人/移除）。色彩为示意，落地时全部走 --lb-* 主题 token。

① 聊天 Tab · 群聊会话

标题=群名+成员数，点标题进成员管理（⑤）。成员条快捷 @；气泡按发言智能体显示头像/名字（已有能力）。输入栏保留当前智能体胶囊 + 一次性 @ 标记。
